## 核心设计原则

1. **应用间绝对隔离** — 数据、用户、机构跨应用互不可见
2. **机构内用户隔离** — 同一 accountId 在不同 orgId 下独立
3. **RBAC 三层权限** — 菜单权限（页面）+ 按钮权限（操作）+ 接口权限（后端）
4. **竞价/招商双模式** — 竞价有规则+保证金，招商无规则+意向人撮合

## 使用原则

- **不要猜测术语含义**，必须查阅对应应用的 `名词解释.md`
- **涉及跨端功能时**，需阅读所有相关端的文档
- **注意 frontmatter 中的 type 字段**：concept（概念）、page-spec（页面规格）、process（流程）、config（配置）、service（服务）
- **文档有层级**：先读总览页（type: overview），再按导航进入子页面
