# 测试评审规范

## 评审维度（6 个）

### 1. 功能完整性
- PRD 中每个功能点是否都有对应的测试场景？
- 是否覆盖了所有用户角色？
- 是否覆盖了所有操作入口？

### 2. 边界条件
- 字段长度边界（最大/最小/空）
- 数值范围边界（0/负数/最大值/小数位）
- 时间边界（跨日/跨月/跨年/节假日）
- 列表边界（空列表/单条/满页/超页）

### 3. 异常流程
- 网络异常（断网/超时/重复提交）
- 并发冲突（同时操作同一资源）
- 权限不足（未授权用户尝试操作）
- 数据异常（脏数据/过期数据/关联数据缺失）

### 4. 数据一致性
- 跨端数据同步是否及时？
- 状态流转在各端是否一致？
- 缓存与数据库是否一致？
- 金额计算精度是否正确？

### 5. 兼容性
- PC 端浏览器兼容（Chrome/Firefox/Edge/Safari）
- 移动端适配（iOS/Android/不同屏幕尺寸）
- 旧版本数据兼容

### 6. 可测试性
- 验收标准是否可量化？
- 测试数据是否可构造？
- 测试环境是否可搭建？

## 测试场景优先级

| 优先级 | 说明 | 要求 |
|:------:|------|------|
| **P0-冒烟** | 核心主流程 | 必须通过，不通过则不发布 |
| **P1-核心** | 重要分支流程 | 必须覆盖 |
| **P2-一般** | 常规功能和交互 | 应当覆盖 |
| **P3-边缘** | 极端边界和罕见场景 | 视时间覆盖 |

## PRD 问题标记规范

在评审中发现的 PRD 问题分为 4 类：

| 类型 | 标记 | 含义 | 示例 |
|------|------|------|------|
| 模糊 | `[模糊]` | 需求描述不明确，无法确定预期行为 | "字段X需要校验"但未定义校验规则 |
| 遗漏 | `[遗漏]` | 缺少必要的功能说明或场景 | 列表页缺少空状态说明 |
| 矛盾 | `[矛盾]` | 不同章节描述冲突 | 「业务流程与业务逻辑」章说"自动通过"，「功能需求」章说"需审核" |
| 不可测 | `[不可测]` | 验收标准无法验证 | "系统应该足够快"但无具体指标 |

## 输出格式

评审报告写入 `output/reviews/qa-review.md`，结构如下：

```markdown
# 测试评审报告

## 评审摘要

| 指标 | 值 |
|------|-----|
| 测试场景覆盖度 | X% |
| PRD 问题总数 | X 个 |
| - 模糊 | X 个 |
| - 遗漏 | X 个 |
| - 矛盾 | X 个 |
| - 不可测 | X 个 |
| 质量风险评估 | 高/中/低 |

## PRD 问题清单

| # | 类型 | PRD 位置 | 问题描述 | 建议修改 |
|---|------|---------|---------|---------|
| 1 | [模糊] | 11.1.1 | 字段X校验规则未定义 | 补充正则表达式和错误提示 |
| 2 | [遗漏] | 11.2.3 | 缺少列表空状态说明 | 补充空状态UI和引导文案 |
| 3 | [矛盾] | 10.1 vs 11.3 | 状态流转描述不一致 | 统一为XX流程 |

## 测试场景矩阵

### [功能模块名称]

| # | 场景 | 优先级 | 前置条件 | 操作步骤 | 预期结果 |
|---|------|:------:|---------|---------|---------|
| 1 | 正常创建 | P0 | 已登录，有权限 | 1.进入页面 2.填写表单 3.提交 | 成功提示，列表新增一条 |
| 2 | 必填字段为空 | P1 | 已登录 | 1.进入页面 2.留空必填字段 3.提交 | 显示错误提示，不提交 |
| 3 | 无权限操作 | P1 | 已登录，无权限 | 1.尝试访问页面 | 403 页面 |
| 4 | 重复提交 | P2 | 已登录 | 1.快速双击提交按钮 | 仅创建一条记录 |

## 边界条件分析

### [功能模块名称]

| 字段/场景 | 边界值 | 预期行为 |
|----------|--------|---------|
| 名称字段 | 空 / 1字符 / 最大长度 / 超长 | 空提示必填，超长截断或提示 |
| 金额字段 | 0 / 负数 / 最大值 / 小数 | 0和负数拒绝，最大值校验 |

## 验收标准建议

### [功能模块名称]

- [ ] 标准1：[具体可验证的描述]
- [ ] 标准2：[具体可验证的描述]
- [ ] 标准3：[具体可验证的描述]
```

## 评审检查清单

- [ ] 每个功能模块是否都有测试场景
- [ ] 测试场景是否覆盖正常+异常流程
- [ ] 边界条件是否分析
- [ ] PRD 问题是否分类标记
- [ ] 验收标准是否可量化可验证
- [ ] 跨端数据一致性场景是否覆盖
- [ ] 权限控制场景是否覆盖
